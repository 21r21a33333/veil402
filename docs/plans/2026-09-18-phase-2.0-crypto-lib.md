# Phase 2.0 — Crypto Foundation + Noir Spike — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the TypeScript crypto library every Veil402 wallet/SDK depends on (keys, note commitments, nullifiers, note encryption, addresses), and a Noir spike that cross-validates the primitives in-circuit and locks the in-circuit key model.

**Architecture:** A framework-free TS package (`packages/crypto`) built on audited primitives — `circomlibjs` (Poseidon + Baby Jubjub), `@noble/ciphers` (ChaCha20-Poly1305), `@noble/hashes` (Blake2b), `@scure/bip39`. Every field value is a BN254 scalar encoded big-endian in 32 bytes; Poseidon MUST equal the Solana `sol_poseidon` syscall and Noir's `poseidon::bn254` (proven in Phase 1). Keys derive from one seed. In-circuit crypto is Poseidon-only; Baby Jubjub is used only off-circuit for ECDH note encryption. A Noir spike cross-checks commitment/nullifier values and measures gate counts.

**Tech Stack:** TypeScript, vitest, circomlibjs, @noble/ciphers, @noble/hashes, @scure/bip39; Noir (nargo beta.22) + Sunspot for the spike; `solana-poseidon` (Rust) as the syscall reference oracle.

**Spec:** `docs/spec/2026-09-18-veil402-design.md` (§3 primitives, §4 keys, §5 note, §8 encryption; this plan implements the client-side of those sections).

**Reuse strategy** (`docs/research/03-reuse-and-language-decision.md`): reuse-first — this TS lib is built on the shared, audited **`circomlibjs`** primitives (Poseidon + **Baby Jubjub**, the same ones RAILGUN / circom / Light use) and follows **RAILGUN's** proven key layout (`nullifyingKey = Poseidon(viewingKey)`, `nullifier = Poseidon(nullifyingKey, leafIndex)`, per-note `random`). We do NOT reinvent primitives or invent a bespoke scheme (x25519 was considered and rejected — it breaks reuse and diversified addresses). Later phases reuse Light's on-chain building blocks (`groth16-solana`, `light-protocol-v1`). We build only the thin glue here and the novel disclosure layer later.

## Global Constraints

- **Field:** BN254 scalar field, modulus `p = 21888242871839275222246405745257275088548364400416034343698204186575808495617`. Every field element serializes to **32 bytes big-endian**.
- **Poseidon must match on-chain/in-circuit.** Known-answer vector (Phase-1-proven): `poseidon([1,2]) = 0x115cc0f5e7d690413df64c6b9662e9cf2a3617f2743245519e19607a4417189a`. Any Poseidon implementation that disagrees is wrong and blocks the phase.
- **In-circuit crypto is Poseidon-only.** No elliptic-curve operations inside any SNARK. Baby Jubjub is used only off-circuit (ECDH for note encryption). The spike (Task 6) must confirm the transaction ownership check needs no in-circuit EC before 2.1 begins.
- **Keys derive from one BIP-39 seed.** Nothing else is persisted server-side; recovery = seed + rescan.
- **No secrets in logs.** Never `console.log` a spending/viewing key or seed in library code.
- **Node ≥ 20, TypeScript ≥ 5.4, ESM modules.** Pin exact dependency versions in `package.json`.
- **Reuse before hand-rolling; minimal LOC.** Any *standard scheme* — hashing, curve ops, AEAD, KDF,
  base58+checksum, mnemonic/seed — comes from an audited library (`circomlibjs`, `@noble/*`,
  `@scure/*`). Hand-write only trivial, protocol-specific glue (struct field packing). If a helper is
  more than a few lines and a library does it, use the library.
- **Every test earns its place.** No tests for config, trivial determinism, struct round-trips of
  library behavior, or "does Poseidon change when an input changes" (that tests the library). Cover
  only what can genuinely regress in *our* code: the Poseidon↔chain KAT, the TS↔Noir parity, the
  encryption round-trip + auth-rejection (a security property), our address struct packing, and the
  end-to-end integration. These few subsume the thin modules.

```ts
export const P = 21888242871839275222246405745257275088548364400416034343698204186575808495617n;
export function assertField(x: bigint): void {
  if (x < 0n || x >= P) throw new Error("value out of BN254 field range");
}
export function toBytes32BE(x: bigint): Uint8Array {
  assertField(x);
  const out = new Uint8Array(32);
  for (let i = 31; i >= 0; i--) { out[i] = Number(x & 0xffn); x >>= 8n; }
  return out;
}
export function fromBytes32BE(b: Uint8Array): bigint {
  if (b.length !== 32) throw new Error("expected 32 bytes");
  let x = 0n;
  for (const byte of b) x = (x << 8n) | BigInt(byte);
  return x;
}
export const toHex = (x: bigint) => "0x" + toBytes32BE(x).reduce((s, b) => s + b.toString(16).padStart(2, "0"), "");
export const fromHex = (h: string) => fromBytes32BE(Uint8Array.from(Buffer.from(h.replace(/^0x/, "").padStart(64, "0"), "hex")));
```

```ts
import { blake2b } from "@noble/hashes/blake2.js";
import { generateMnemonic, mnemonicToSeedSync } from "@scure/bip39";
import { wordlist } from "@scure/bip39/wordlists/english.js";
import { poseidon } from "./poseidon";
import { P, fromBytes32BE } from "./field";

export type SpendKeys = {
  spendingKey: bigint; viewingKey: bigint; nullifyingKey: bigint; spendingPubKey: bigint; mpk: bigint;
};
function h1(tag: string, seed: Uint8Array): bigint {
  const t = new TextEncoder().encode(tag);
  const buf = new Uint8Array(t.length + seed.length); buf.set(t); buf.set(seed, t.length);
  return fromBytes32BE(blake2b(buf, { dkLen: 32 })) % P;
}
export const newMnemonic = () => generateMnemonic(wordlist, 256);
export const seedFromMnemonic = (m: string) => mnemonicToSeedSync(m);
export function deriveKeys(seed: Uint8Array): SpendKeys {
  const spendingKey = h1("veil-spend", seed);
  const viewingKey = h1("veil-view", seed);
  const spendingPubKey = poseidon([spendingKey]);
  const nullifyingKey = poseidon([viewingKey]);
  const mpk = poseidon([spendingPubKey, nullifyingKey]);
  return { spendingKey, viewingKey, nullifyingKey, spendingPubKey, mpk };
}
```

```ts
import { buildBabyjub } from "circomlibjs";
let _bj: any = null;
export async function initBabyjub(): Promise<void> { if (!_bj) _bj = await buildBabyjub(); }
function scalar(k: bigint): bigint { const o = _bj.subOrder as bigint; return ((k % o) + o) % o; } // use the lib's subgroup order (verified in the pre-flight audit)
export function viewingPubKey(viewingKey: bigint): Uint8Array {
  const pt = _bj.mulPointEscalar(_bj.Base8, scalar(viewingKey));
  return _bj.packPoint(pt);
}
export function ecdhShared(k: bigint, packed: Uint8Array): Uint8Array {
  const pt = _bj.unpackPoint(packed);
  return _bj.packPoint(_bj.mulPointEscalar(pt, scalar(k)));
}
export function babyjubBase(): Uint8Array { return _bj.packPoint(_bj.Base8); }
export function mulBase(k: bigint): Uint8Array { return _bj.packPoint(_bj.mulPointEscalar(_bj.Base8, scalar(k))); }
```

```ts
import { chacha20poly1305 } from "@noble/ciphers/chacha.js";
import { blake2b } from "@noble/hashes/blake2.js";
import { randomBytes } from "@noble/ciphers/utils.js";
import { toBytes32BE, fromBytes32BE, P } from "./field";
import { viewingPubKey, ecdhShared, mulBase } from "./ecdh";
import { randomField } from "./note";

export type NotePlaintext = { value: bigint; assetId: bigint; random: bigint; mpk: bigint };
const enc = (pt: NotePlaintext) => {
  const out = new Uint8Array(128);
  out.set(toBytes32BE(pt.value), 0); out.set(toBytes32BE(pt.assetId), 32);
  out.set(toBytes32BE(pt.random), 64); out.set(toBytes32BE(pt.mpk), 96);
  return out;
};
const dec = (b: Uint8Array): NotePlaintext => ({
  value: fromBytes32BE(b.slice(0, 32)), assetId: fromBytes32BE(b.slice(32, 64)),
  random: fromBytes32BE(b.slice(64, 96)), mpk: fromBytes32BE(b.slice(96, 128)),
});
const key = (shared: Uint8Array) => blake2b(shared, { dkLen: 32 });

export function encryptNote(pt: NotePlaintext, recipientVpk: Uint8Array): Uint8Array {
  const ephSk = randomField();
  const ephPk = mulBase(ephSk);                       // sender ephemeral public
  const shared = ecdhShared(ephSk, recipientVpk);     // = ecdhShared(viewingKey, ephPk) for the recipient
  const nonce = randomBytes(12);
  const ct = chacha20poly1305(key(shared), nonce).encrypt(enc(pt));
  const blob = new Uint8Array(32 + 12 + ct.length);
  blob.set(ephPk, 0); blob.set(nonce, 32); blob.set(ct, 44);
  return blob;
}
export function tryDecryptNote(blob: Uint8Array, viewingKey: bigint): NotePlaintext | null {
  try {
    const ephPk = blob.slice(0, 32), nonce = blob.slice(32, 44), ct = blob.slice(44);
    const shared = ecdhShared(viewingKey, ephPk);
    const pt = dec(chacha20poly1305(key(shared), nonce).decrypt(ct));
    if (pt.value >= P || pt.assetId >= P || pt.random >= P || pt.mpk >= P) return null;
    return pt;
  } catch { return null; }
}
```

```ts
import { base58check } from "@scure/base";
import { blake2b } from "@noble/hashes/blake2.js";
import { toBytes32BE, fromBytes32BE } from "./field";
import { viewingPubKey } from "./ecdh";
import type { SpendKeys } from "./keys";

// @scure/base handles base58 + the 4-byte checksum; we only pack our struct.
const codec = base58check((d) => blake2b(d, { dkLen: 32 }));
export type Address = { mpk: bigint; vpk: Uint8Array; diversifier: bigint };
const u64BE = (x: bigint) => { const o = new Uint8Array(8); for (let i = 7; i >= 0; i--) { o[i] = Number(x & 0xffn); x >>= 8n; } return o; };
const u64FromBE = (b: Uint8Array) => b.reduce((x, y) => (x << 8n) | BigInt(y), 0n);
export function encodeAddress(a: Address): string {
  const body = new Uint8Array(72);
  body.set(toBytes32BE(a.mpk), 0); body.set(a.vpk, 32); body.set(u64BE(a.diversifier), 64);
  return codec.encode(body);
}
export function decodeAddress(s: string): Address {
  const body = codec.decode(s);            // throws on a bad checksum
  if (body.length !== 72) throw new Error("bad address length");
  return { mpk: fromBytes32BE(body.slice(0, 32)), vpk: body.slice(32, 64), diversifier: u64FromBE(body.slice(64, 72)) };
}
export const defaultAddress = (k: SpendKeys): Address => ({ mpk: k.mpk, vpk: viewingPubKey(k.viewingKey), diversifier: 0n });
export const diversifiedAddress = (k: SpendKeys, index: bigint): Address => ({ mpk: k.mpk, vpk: viewingPubKey(k.viewingKey), diversifier: index });
```
